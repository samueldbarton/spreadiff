# Hosted-test fixtures

Pairs of real `.xlsx` files with the results LibreOffice gives for them,
used by `npm run test:hosted`. Generated by
`bench/trace-eval/export-fixtures.ts` after `npm run bench:trace`; don't
edit them by hand.

Each folder has:
- `old.xlsx` and `new.xlsx`: before and after scripted edits, both
  recalculated and saved by LibreOffice;
- `stale.xlsx` (most): the value edits written into `old.xlsx` without
  recalculating;
- `uncached.xlsx` (the generated models): the edits applied by openpyxl,
  which saves formulas without values;
- `expected.json`: for each changed cell, its kind and the edits that
  caused it. These come from LibreOffice's leave-one-out recalculations,
  never from spreadiff's own trace. It also holds LibreOffice's values
  for the stale and uncached checks.

`three_statement`, `budget`, `inventory`, `loan` and `commission` are
models generated by `bench/trace-eval/models.py`. The others are from the
[Apache POI](https://github.com/apache/poi) test corpus
(`test-data/spreadsheet`), Apache License 2.0. They were modified: the
scripted edits were applied and the files re-saved by LibreOffice.
